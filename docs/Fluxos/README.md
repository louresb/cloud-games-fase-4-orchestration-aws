## Diretriz rápida para adição de novas categorias

- Mantenha cada categoria em um arquivo separado dentro de `docs/Fluxos/` com um nome claro e idêntico ao do sumário.
- Atualize o Sumário neste `FLUXOS.md` apontando para o novo arquivo.
- Use o template de fluxo (abaixo) para manter consistência.
